## English (Apple often prefers)

```
Operax Mobile is a B2B workforce app for companies that already use the Operax CRM.

DEMO ACCOUNT
Company code: OPRX
Email: [FILL_REVIEW_EMAIL]
Password: [FILL_REVIEW_PASSWORD]
MFA: disabled for this review tenant (or TOTP: [FILL])

HOW TO TEST
1. Open the app → enter company code, email, password → Sign in
2. Home "Atendimento" shows conversations assigned to the agent
3. Tap the hamburger menu (top-left) → Queue drawer slides from the left
4. Tap "Assumir" on a queued conversation → chat opens with ownership
5. Send a message; open ⋯ for claim/release/close actions
6. Tabs: Agenda, Avisos (notifications), Mais (more)

NOTES
- Signing in on mobile ends the web session (exclusive session by design)
- Push notifications require device permission; core chat works without push
- App requires an active Operax tenant; not a consumer self-serve product

Privacy: https://operax.digital/privacidade-mobile
Support: suporte@operax.digital
```
